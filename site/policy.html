For IT administrators

Policy generator

The shipped defaults are the recommendation. Pick a preset, set the few values most sites change, and copy the result.

Outputs: a PowerShell script that writes the values into a GPO, a .reg file for one test machine, and a table for setting the same values by hand in the Group Policy Management Editor. Only values that differ from the defaults, or that the preset sets, are included. This page runs entirely in your browser and sends nothing anywhere. Background: RECOMMENDED-POLICY.md.

Preset
Common settings

Leave a field at "Not configured" to keep the shipped default.

Output options

Becomes the script's default for -GpoName. Leave empty to pass it when you run the script.

Tray app settings go to

Engine settings are always computer policy. Machine policy wins over user policy for the tray.

All settings

Every setting the Group Policy templates define, grouped as in the editor. Common settings above are not repeated. Custom targets are a list policy: set them in the editor.
